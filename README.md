# 受払管理アプリ

- Embedded Pythonを用いた顧客「美濃関・麦酒」での受払管理簿の維持管理支援アプリです
- Python 初学者がコース学習中に製作したものになります


## 特徴

- Python ソースコードの実装方法
  - 日本語で実装しています
- Embedded 環境や動作場所に極力依存しないような工夫を施しています


## Embedded Pythonの理由

- お客様がITにそれほど詳しくないので、極力面倒な操作を省略したい
- 担当が初学者なため、動作環境構築に手間取らないようにしたい
- 動作環境にできるだけ依存せず動作環境を特定しやすくしたい
